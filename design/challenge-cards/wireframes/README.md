# Wireframes

Dieses Verzeichnis nimmt die maßhaltigen Low-Fidelity-Wireframes auf.

Das erste Wireframe-Paket soll mindestens enthalten:

- `challenge-card-2.svg`,
- `challenge-card-3.svg`,
- `challenge-card-4.svg`,
- dokumentierte Pixelmaße und Abstände,
- Testfälle für ein offenes Konzept, einen langen Namen und eine lange Regel,
- eine bewusst entschiedene Darstellung ohne Zusatzregel.

Die Wireframes enthalten noch keine finale Farbpalette, keine finale Schrift und keine ausformulierten Zutatenillustrationen. Sie prüfen ausschließlich Informationshierarchie, Geometrie und Lesbarkeit.

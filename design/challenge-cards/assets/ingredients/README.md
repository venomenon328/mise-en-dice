# Konkrete Zutaten

Hier liegen später Illustrationen eindeutig bestimmter Zutaten, beispielsweise Tofu, Mango oder Schweinebauch.

Eine konkrete Zutat wird grundsätzlich als einzelnes, klar erkennbares Motiv dargestellt. Dateinamen sollen stabil, kleingeschrieben und mit Bindestrichen gebildet werden, beispielsweise:

```text
tofu.png
pak-choi.png
schweinebauch.png
```

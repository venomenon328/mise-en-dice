# Konkrete Zutaten

Hier liegen ausschließlich **freigegebene Produktionsassets** eindeutig bestimmter Zutaten.

Eine konkrete Zutat wird grundsätzlich als einzelnes klar erkennbares Hauptmotiv dargestellt. Mehrere natürliche Einheiten sind nur zulässig, wenn sie zur üblichen Erscheinungsform gehören oder die Erkennbarkeit verbessern.

Vor Aufnahme sind der [`Illustration Guide`](../../illustration-system/ILLUSTRATION_GUIDE.md) und insbesondere die Nachbarschaftsprüfung aus [`CONFUSABLES.md`](../../illustration-system/CONFUSABLES.md) anzuwenden.

Dateinamen werden stabil, kleingeschrieben und mit Bindestrichen gebildet, beispielsweise:

```text
tofu.png
pak-choi.png
schweinebauch.png
```

# Asset-Review

Dieses Verzeichnis ist für bewusst versionierte Review-Artefakte gedacht, beispielsweise direkte Nachbarschaftsvergleiche oder Karten-Kleinformatprüfungen.

Review-Dateien sind keine Produktionsassets und werden nicht in `ASSET_INDEX.csv` aufgenommen. Temporäre Renderings müssen nicht dauerhaft eingecheckt werden, sofern sie keine neue verbindliche Designentscheidung dokumentieren.

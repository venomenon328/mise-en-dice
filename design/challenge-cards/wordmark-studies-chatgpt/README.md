# Expressive wordmark studies

This directory contains the independent ChatGPT study pass for Issue #130.

The studies intentionally move beyond purely typographic treatments. They explore a custom-lettering-like `Mise en Dice` wordmark with a subordinate `en`, an integrated six-sided die, warm gold/orange surfaces, dark espresso outlines, and controlled swashes.

## Files

- `wordmark-study-a.svg` — Script Ribbon
- `wordmark-study-b.svg` — Kitchen Crest
- `wordmark-study-c.svg` — Refined Game Accent
- `WORDMARK_STUDIES.md` — design rationale and first-pass assessment
- `validate_wordmark_studies.py` — structural validation
- `renders/wordmark-review.svg` — comparison montage including 1200-header and native 320-card header checks

## Status

These are **review studies**, not production brand assets. No study is frozen as the final wordmark until the user explicitly selects a direction and the selected study receives a dedicated cleanup/finalisation pass.

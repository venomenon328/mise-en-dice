# Herunterladbare Designpakete

Dieses Verzeichnis enthält bewusst gebündelte ZIP-Pakete für den einfachen Zugriff außerhalb der GitHub-Einzeldateiansicht.

## Visual Foundations v1

[`challenge-card-visual-foundations-v1.zip`](challenge-card-visual-foundations-v1.zip) enthält:

- beide Style-Studies mit und ohne Zusatzregel,
- die vier SVG-Quellen bei `1200 × 1200 px`,
- vier explizite SVG-Prüfexporte und eine Vergleichsansicht bei `320 × 320 px`,
- den deterministischen SVG-Generator,
- die dokumentierten visuellen Grundlagen.

Die ZIP ist ein Distributionsartefakt. Verbindliche Änderungen erfolgen weiterhin an den entpackten Dateien im Repository; anschließend wird das Paket bewusst neu erstellt.

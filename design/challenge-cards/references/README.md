# Referenzen

Dieses Verzeichnis enthält visuelle Quellen, aus denen die Marken- und Stilrichtung abgeleitet wird. Referenzen sind **keine Templates** und dürfen nicht ungeprüft als Kartenhintergrund verwendet werden.

## Discord-Banner

`discord-bot-banner-reference.jpg` ist eine verkleinerte Arbeitskopie des derzeitigen Discord-Bot-Banners.

Relevante Merkmale:

- warme orange-goldene Küchenatmosphäre,
- dunkle Utensiliensilhouetten,
- Holzfläche,
- comicartige Lebensmittel mit kräftiger Kontur,
- Lichtfokus in der Bildmitte.

Für Challenge-Cards gilt zusätzlich:

- Das breite Banner wird nicht lediglich beschnitten.
- Dekorative Lebensmittel dürfen im Vorgabenbereich nicht wie Pflichtbestandteile wirken.
- Logo, Text und Slots werden als feste, versionierte Kartenelemente aufgebaut.
